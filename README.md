# Agence Freelance Pro - Site Complet

## 🚀 À Propos

**Agence Freelance Pro** est un site web professionnel complet pour une agence de freelance spécialisée dans le développement web, le design et le marketing digital.

## ✨ Fonctionnalités

### 1. **Navigation Professionnelle**
   - Barre de navigation sticky avec logo personnalisé
   - Liens de navigation fluides vers toutes les sections
   - Design responsive et mobile-friendly

### 2. **Section Héro**
   - Titre accrocheur avec appel à l'action
   - Gradient coloré moderne
   - Design attractif et conversant

### 3. **Services**
   - 6 services principaux avec descriptions
   - Icônes Font Awesome
   - Hover animations fluides
   - Grille responsive

### 4. **Portfolio**
   - Showcase de 4 projets réalisés
   - Catégories et tags
   - Design moderne avec images/icônes
   - Effets de hover professionnels

### 5. **Équipe**
   - Présentation de 4 membres d'équipe
   - Rôles et expertises
   - Emojis professionnels
   - Design personnalisé

### 6. **Tarification**
   - 3 plans tarifaires (Starter, Professionnel, Enterprise)
   - Plan mis en avant avec badge "Populaire"
   - Liste des features pour chaque plan
   - Design attractif et conversant

### 7. **Formulaire de Contact**
   - Form moderne et fonctionnelle
   - Champs obligatoires avec validation
   - Informations de contact complètes
   - Horaires et localisation

### 8. **Footer Professionnel**
   - Liens rapides
   - Réseaux sociaux
   - Mentions légales
   - Design cohérent

5. **Active Navigation**: Suivi de la section active

## 🚀 Installation & Utilisation

1. **Cloner le repository**
   ```bash
   git clone https://github.com/Emanuelrobert1/Agence-free-lance-.git
   ```

2. **Ouvrir le fichier**
   - Ouvrir `index.html` dans un navigateur web
   - Ou utiliser un serveur local (Live Server, Python http.server, etc.)

3. **Personnalisation**
   - Modifier les textes et contenus dans `index.html`
   - Ajuster les couleurs dans `css/style.css` (variables CSS)
   - Ajouter des fonctionnalités dans `js/script.js`

## 📝 Sections Personnalisables

### Informations de Contact
Modifiez dans `index.html` section contact:
- Adresse
- Téléphone
- Email
- Horaires

### Services
Ajoutez ou modifiez les services dans la section `#services`

### Portfolio
Mettez à jour les projets dans la section `#portfolio`

### Équipe
Modifiez les membres dans la section `#equipe`

### Tarifs
Ajustez les prix dans la section `#tarifs`
